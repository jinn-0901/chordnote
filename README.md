# Chordnote

무료 브라우저 기반 오디오 코드 분석 웹앱입니다.

## 기능
- 오디오 파일 업로드 (최대 80MB)
- 브라우저에서 음원의 조성과 시간대별 코드 추정
- 코드 구간을 눌러 해당 위치 재생

## 지원 입력
MP3, WAV, M4A, AAC, OGG, FLAC 등 브라우저에서 디코딩할 수 있는 오디오 파일을 지원합니다.

유튜브 링크만으로는 공식 임베드 플레이어의 오디오를 다른 웹앱이 직접 읽을 수 없습니다. 따라서 임의의 유튜브 영상에서 음원을 자동 추출하는 기능은 제공하지 않습니다. 본인이 사용 권한을 가진 오디오 파일을 업로드해 분석할 수 있습니다.

## 분석 안내
브라우저 Web Audio API로 오디오를 분석해 조성과 코드 진행을 추정합니다. 실제 연주 코드와 다를 수 있으므로 참고용으로 사용해 주세요.

## 실행 및 배포
별도 빌드 도구 없이 정적 파일로 실행하며, GitHub Pages 배포를 지원합니다. React 18은 esm.sh CDN에서 불러옵니다.
